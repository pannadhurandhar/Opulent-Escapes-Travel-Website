Create a modern, responsive, multipage travel agency website for Wander Trails, focused on generating customer enquiries and trip bookings.
Design and Branding: Use a bright, colourful, family-friendly design with teal, orange, cream, and white. Include beautiful travel photography, rounded cards, playful design elements, clean typography, subtle animations, and a welcoming travel-inspired aesthetic.
Pages Required:
1.	Home: Attractive hero section with the headline “Your Next Adventure, Planned”, a strong CTA, destination search bar, featured packages, popular destinations, why choose us, testimonials, and a footer.
2.	Tour Packages: Display domestic and international holiday packages in attractive cards with destination images, prices, ratings, duration, and View Details buttons. Add functional search, destination filters, duration filters, and price range filters.
3.	Package Details: Create individual detail pages for each tour, including a large banner image, itinerary, trip highlights, duration, starting price, inclusions, exclusions, FAQs, and Enquire Now / Book Now buttons.
4.	Contact Us: Include a contact form, WhatsApp contact button, agency contact details, location, and a custom itinerary enquiry section.
Sample Destinations: Kerala, Goa, Manali, Dubai, Bali, and Thailand. Add realistic travel imagery and sample pricing in Indian rupees.
Functional Requirements:
•	Build using React with reusable components and React Router for navigation.
•	Make every page responsive and mobile-friendly, with a collapsible mobile navigation menu.
•	Ensure all navigation links, search, filters, and package detail links work correctly.
•	Add enquiry forms that collect name, email, phone number, preferred travel dates, number of travellers, and destination.
•	Integrate WhatsApp contact with a pre-filled message.
•	Include booking interactions and prepare the interface for future online payment integration.
•	Add clear loading, validation, success, and empty-search states where appropriate.
User Experience: Keep the navigation intuitive, package information easy to compare, and CTAs prominent. Use consistent spacing, accessible contrast, descriptive image alt text, and a professional footer across all pages.
Important: Use realistic sample content rather than placeholder text. Create separate, navigable pages rather than a single long landing page. Keep the code clean, maintainable, and ready for future backend integration. Clearly identify sample prices and do not imply that bookings or payments are confirmed unless the relevant functionality is connected.
The overall website should feel trustworthy, cheerful, travel-focused, and suitable for families, couples, and groups planning domestic or international holidays.
